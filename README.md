# Oak & Ember Coffee — Coffee Shop Website

**Project Type:** Website Design & Front-End Development

**Overview**

Oak & Ember Coffee is a concept website for a cozy, modern coffee shop. The design uses warm neutral colors, clean typography, and coffee imagery to create a welcoming atmosphere.

**Features**
- Responsive layout for desktop and mobile screens
- Hero section with coffee imagery and a clear call to action
- Menu section featuring drinks and prices
- About section introducing the café's story
- Visit section with location and opening hours information

**Tools & Technologies**
- HTML5
- CSS3
- Responsive web design

**Project Goal**

To practice building a visually appealing, easy-to-navigate website for a small business, with a focus on layout, typography, and responsive design.
